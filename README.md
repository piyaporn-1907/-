# 🏢 ระบบจัดการหอพักนักศึกษา (Student Dormitory Management System)

เว็บแอปพลิเคชันและระบบฐานข้อมูลสำหรับบริหารจัดการหอพักนักศึกษาแบบครบวงจร รองรับ 3 กลุ่มผู้ใช้งานหลัก (นักศึกษา, ผู้ดูแลหอพัก, เจ้าของหอพัก) พร้อมระบบจัดการห้องพัก การจอง การชำระเงินออนไลน์ผ่านการแนบสลิป การแจ้งซ่อมแซม และสรุปรายงานรายรับ

---

## 📌 จุดเด่นและวัตถุประสงค์ของระบบ
* **จัดเก็บข้อมูลอย่างเป็นระบบ:** แปลงเอกสารกระดาษให้เป็นระบบฐานข้อมูลเชิงสัมพันธ์ (Relational Database)
* **อำนวยความสะดวกในการจองห้องพัก:** ค้นหาห้องว่างตามชั้นและประเภทห้อง และส่งคำร้องจองออนไลน์ได้ทันที
* **ระบบแจ้งซ่อมแซมติดตามสถานะ:** นักศึกษาสามารถแจ้งปัญหาอุปกรณ์ชำระ พร้อมติดตามสถานะแบบเรียลไทม์
* **ชำระค่าเช่าออนไลน์:** แนบสลิปโอนเงินผ่านระบบ และให้ผู้ดูแลตรวจสอบอนุมัติ
* **แดชบอร์ดสรุปผลสำหรับผู้บริหาร:** เจ้าของหอพักสามารถดูสถิติอัตราการเข้าพักและรายรับรวมได้ทันที

---

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้งาน **SQLite** (จัดเก็บในไฟล์ `dormitory.db`) และมีไฟล์ **`schema.sql`** สำหรับนำไปใช้กับ MySQL / PostgreSQL / MariaDB

### รายละเอียดตารางข้อมูล (Tables)
1. **`users`**: ตารางจัดเก็บข้อมูลผู้ใช้งาน (นักศึกษา, ผู้ดูแลหอพัก, เจ้าของหอพัก)
2. **`rooms`**: ตารางจัดเก็บข้อมูลห้องพัก (หมายเลขห้อง, ชั้น, ประเภทห้อง, ราคาค่าเช่า, เงินประกัน, สถานะห้อง)
3. **`bookings`**: ตารางคำร้องขอจองห้องพักและการอนุมัติ
4. **`rent_bills`**: ตารางจัดเก็บรอบบิลค่าเช่า ค่าน้ำ ค่าไฟ สถานะการชำระเงิน และลิงก์สลิปโอนเงิน
5. **`repairs`**: ตารางจัดเก็บการแจ้งซ่อมแซม หมวดหมู่ ระดับความเร่งด่วน และสถานะการซ่อม
6. **`announcements`**: ตารางข่าวสารประกาศแจ้งเตือนจากหอพัก

## 👥 ฟังก์ชันตามบทบาทผู้ใช้งาน (User Capabilities)

### 1. นักศึกษา (ผู้พักอาศัย)
- ดูห้องพักที่ว่างและข้อมูลรายละเอียดห้อง
- ส่งคำร้องขอจองห้องพักออนไลน์
- ส่งเรื่องแจ้งซ่อมอุปกรณ์ชำรุด พร้อมระบุความเร่งด่วน
- ตรวจสอบบิลค่าเช่าประจำเดือน และอัปโหลดสลิปโอนเงิน
- อ่านประกาศข่าวสารสำคัญจากหอพัก

### 2. ผู้ดูแลหอพัก (Caretaker / Admin)
- จัดการและอัปเดตข้อมูลห้องพัก
- พิจารณาอนุมัติ / ปฏิเสธ คำร้องจองห้องพัก
- ตรวจสอบสลิปโอนเงินค่าเช่าและอนุมัติการชำระ
- รับเรื่องแจ้งซ่อมและอัปเดตสถานะ (กำลังซ่อม / เสร็จสิ้น)
- สร้างและลงประกาศแจ้งเตือนนักศึกษา

### 3. เจ้าของหอพัก (Owner)
- ดูรายงานสรุปรายรับหอพักประจำเดือน (รายรับจริง vs ยอดค้างชำระ)
- ดูสถิติอัตราการเข้าพัก (Occupancy Rate) ผ่านกราฟวงกลม (Doughnut Chart)
- ตรวจสอบภาพรวมสถานะห้องพักและประวัติย้อนหลังทั้งหมด

## 🚀 ขั้นตอนการติดตั้งและเริ่มใช้งาน (Installation & Setup)

### 1. ความต้องการของระบบ (Prerequisites)
- Python 3.8 ขึ้นไป

### 2. ติดตั้ง Dependencies
```bash
pip install flask flask-cors
```

### 3. สร้างและสร้างข้อมูลตัวอย่างในฐานข้อมูล (Database Initialization)
```bash
python database.py
```
*(ระบบจะสร้างไฟล์ `dormitory.db` พร้อมข้อมูลตัวอย่างสำหรับทดสอบโดยอัตโนมัติ)*

### 4. รันเซิร์ฟเวอร์เว็บแอปพลิเคชัน (Start Web Server)
```bash
python app.py
```
เปิดบราวเซอร์ไปที่ URL: **`http://127.0.0.1:5000`**

## 📤 ขั้นตอนการนำโปรเจกต์ขึ้น GitHub (Push to GitHub)

หากต้องการนำซอร์สโค้ดนี้ขึ้นบัญชี GitHub ของคุณ ให้ทำตามขั้นตอนดังนี้:

### 1. สร้าง Local Git Repository
เปิด Terminal ในโฟลเดอร์โปรเจกต์นี้ แล้วพิมพ์:
```bash
git init
git add .
git commit -m "Initial commit: Student Dormitory Management System with SQLite Database"
```

### 2. สร้าง Repository บน GitHub
1. ไปที่เว็บไซต์ [GitHub.com](https://github.com) แล้วเข้าสู่ระบบ
2. คลิกปุ่ม **"+"** มุมขวาบน -> เลือก **"New repository"**
3. ตั้งชื่อ Repository เช่น `student-dormitory-management`
4. ตั้งค่าเป็น Public หรือ Private ตามต้องการ (ไม่ต้องเลือก Add a README file เพราะในเครื่องเรามีแล้ว)
5. คลิก **"Create repository"**

### 3. เชื่อมต่อ Local Git เข้ากับ GitHub และ Push โค้ด
คัดลอกคำสั่งที่ได้จากหน้า GitHub มาวางใน Terminal (เปลี่ยน `YOUR_USERNAME` เป็นชื่อผู้ใช้ของคุณ):
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/student-dormitory-management.git
git push -u origin main
```
